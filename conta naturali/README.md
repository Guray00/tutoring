Scrivere un programma che, dati n numeri inseriti dall'utente, mostri a schermo quanti di questi sono numeri naturali. 

Nota: un numero e' detto naturale se maggiore di 1.

## Esempio

```plaintext
Quanti numeri vuoi inserire? 4
Inserisci un numero: 3
Inserisci un numero: -1
Inserisci un numero: -4
Inserisci un numero: 0
```
